About

A gold processing plant and an executive’s inbox look nothing alike. Both are systems with inputs, throughput, and failure points, and both tend to fail the same way: when nobody owns the handoffs.

I studied metallurgical engineering to run the first kind. I built a track record in remote operations running the second. The mine work taught me to read a process end to end before I touch it. The operations work taught me to keep a system running with no one standing over my shoulder. Neither track is a hobby or a side gig. Both are load-bearing.
